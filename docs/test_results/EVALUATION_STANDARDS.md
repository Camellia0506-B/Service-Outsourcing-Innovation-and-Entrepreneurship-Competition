# 人岗匹配与画像准确率 — 量化可执行标准

本文档对应赛题中“人岗匹配的关键技能匹配准确率”与“岗位画像/学生画像关键信息准确率”的**企业官方可量化、可执行**的判定方式，便于学生自测与评委验收。

---

## 一、标准A：人岗匹配关键技能准确率 ≥ 80%

### 口径说明

- **定义**：随机抽取 **3 名学生**，经与岗位画像匹配后，其**专业技能要求匹配信息准确率不低于 80%**。
- **操作含义**：将岗位的**专业技能拆成技能知识点**，与学生**已掌握的知识点**对比，**正确匹配数 / 岗位要求技能数 ≥ 80%**，能真实反映学生满足情况。

### 可执行步骤

1. 从业务库（如 MySQL）中**随机抽取 3 名**有技能标签的学生（如 `profile_skills` 非空）。
2. 对每名学生调用 **推荐接口**（如 `POST /api/v1/matching/recommend-jobs`），取 **匹配分最高的 1 个岗位（Top1）**。
3. 获取该岗位的**岗位画像**（如 `POST /api/v1/job/profile/detail`），从 `requirements.professional_skills` 中提取**岗位要求技能知识点列表**。
4. 获取该学生的**学生能力画像**（如 `POST /api/v1/student/ability-profile`），从 `professional_skills` 中提取**学生已掌握技能知识点列表**。
5. 计算**单名学生准确率** = （岗位要求技能中与学生掌握技能匹配的数量）/ （岗位要求技能总数）× 100%。
6. **标准A通过条件**：3 名学生的**平均准确率 ≥ 80%**。

### 自动化脚本与输出

- **脚本**：`python test_skill_match_accuracy.py`
- **输出**：控制台打印每名学生明细与“通过/不通过”；结果写入 `test_results/skill_match_report.json`。
- **可选参数**：`--ai-base-url`、`--mysql-host`、`--mysql-db` 等，见脚本 `--help`。

## 二、标准B：岗位画像与学生画像关键信息准确率 ≥ 90%

### 口径说明

- **定义**：**关键信息**包含 **学历、专业、证书** 三项。抽取 **10 名**“人岗匹配成功”的学生，逐人核对其学生画像与岗位画像在上述 **3 项**上是否一致；**任一项不符合即视为该学生不合格**。
- **通过条件**：10 名学生中 **至少 9 名三项全部符合**，即合格率 ≥ 90%。

### 可执行步骤

1. 从业务库中选取候选用户（建议优先有档案+技能的用户）。
2. 对每名用户调用推荐接口，若返回至少 1 个推荐岗位，则视为**匹配成功**；直至收集到 **10 名**匹配成功样本。
3. 对每名样本：
   - 从业务库/学生画像获取：**学历、专业、证书列表**；
   - 从岗位画像获取：岗位要求的**学历、专业偏好、证书要求**；
   - 逐项比对：学历是否满足、专业是否在岗位偏好内、证书是否覆盖岗位要求。
4. **单名学生合格**：学历、专业、证书 **3 项均符合**；任一项不符合则为不合格。
5. **标准B通过条件**：10 名中 **合格人数 ≥ 9**（即 90%）。

### 自动化脚本与输出

- **脚本**：`python test_profile_accuracy.py`
- **可选参数**：`--sample-size 10`、`--ai-base-url` 等。
- **输出**：明细写入 `test_results/profile_accuracy_report.json`；若存在标准A报告，会更新 `test_results/final_report.md`。

## 三、如何用真实数据跑通

1. **数据**：使用真实或接近真实的**岗位画像**与**学生档案/能力画像**（避免大量“待补充”等占位符导致匹配被跳过）。
2. **服务**：启动 **AI 服务**（如 5002 端口）及（若需要）**Java 后端**（如 5000 端口），确保推荐与画像接口可用。
3. **执行顺序**（建议）：
   ```bash
   python test_skill_match_accuracy.py --ai-base-url http://127.0.0.1:5002/api/v1
   python test_profile_accuracy.py --sample-size 10 --ai-base-url http://127.0.0.1:5002/api/v1
   ```
4. **汇总报告**：查看 `test_results/final_report.md` 或直接查看两个 JSON 报告中的 `passed`、`average_accuracy`、`pass_rate` 等字段。

## 四、指标汇总表（与 final_report 一致）

| 指标 | 阈值 | 判定方式 |
|------|------|----------|
| 标准A：人岗匹配关键技能准确率 | ≥ 80% | 随机 3 名学生 × Top1 岗位，技能知识点匹配率平均值 |
| 标准B：画像关键信息准确率 | ≥ 90% | 10 名匹配成功学生 × 学历/专业/证书 3 项全符合率 |

上述标准可直接用于学生自测与企业/评委量化验收。
