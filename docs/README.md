# GradQuest（职业规划智能体）

本仓库按模块划分为：

- `frontend/`：前端静态站点（HTML/CSS/JS）
- `backend/`：后端
- `AI算法/`：算法/AI 服务
- `database.sql`：数据库初始化脚本

## 文档入口

- `docs/API文档.md`：接口文档总入口（含后端/前端/PDF 智能体）
- `docs/前端说明.md`：前端项目说明
- `docs/启动指南.md`：启动说明与常见问题

## 脚本与工具

为保持根目录简洁，启动脚本与评测脚本已集中放在：

- `docs/scripts/`：`start-*.bat`、`start_ai_service*.ps1/.cmd`
- `docs/tools/`：数据生成、评测与报告构建脚本

## 配置文件

根目录仅保留少量关键文件（如 `.gitignore`、`database.sql`）。其余依赖/配置文件已归档在：

- `docs/config/`：`package.json`、`package-lock.json`、`requirements*.txt`
