# 比赛指标验证说明（可量化可执行标准）

本文档面向企业/评委，说明如何用项目内脚本对赛题两条指标进行量化验证。

---

## 一、标准 A：人岗匹配关键技能匹配准确率 ≥ 80%

**赛题表述**  
随机抽取 3 名学生，经过与岗位画像匹配后，其专业技能要求匹配信息准确率不低于 80%。即把专业技能拆分成技能知识点后与学生掌握的知识点对比，正确匹配率能达到 80% 以上，能够真实反映学生满足情况。

**可执行定义**

| 项目 | 说明 |
|------|------|
| 抽样方式 | 从数据库随机抽取 3 名有技能标签的学生 |
| 匹配流程 | 对每人调用人岗推荐接口取 Top1 岗位，再取该岗位画像中的专业技能要求 |
| 准确率计算 | 单生准确率 = 匹配到的岗位要求技能数 ÷ 岗位要求技能总数 × 100%（技能知识点级别对比，含同义/模糊匹配） |
| 通过条件 | 3 名学生平均准确率 ≥ 80% |

**验证命令**

```bash
# 项目根目录执行（需先启动 AI 服务端口 5002 与 MySQL）
python test_skill_match_accuracy.py
```

**结果位置**  
`test_results/skill_match_report.json`（控制台同时打印通过/不通过及每名学生明细）

## 二、标准 B：岗位画像与学生画像关键信息准确率 > 90%

**赛题表述**  
关键信息包含学历、专业、证书。抽取 10 名人岗匹配成功的学生，看这 3 项信息与岗位画像学历、专业、证书是否符合；这 3 项中有一个不符合的即为不合格。10 个学生中有 9 个完全符合的即为 90%。

**可执行定义**

| 项目 | 说明 |
|------|------|
| 抽样方式 | 抽取 10 名“人岗匹配成功”的学生（本系统以 recommend-jobs 能返回 Top1 岗位为可执行定义） |
| 关键信息 | 学历、专业、证书（共 3 项） |
| 合格判定 | 每名学生 3 项与岗位画像要求全部符合才计为合格；任一项不符合即该生不合格 |
| 通过条件 | 合格人数 ÷ 10 ≥ 90%（即至少 9 人三项完全符合） |

**验证命令**

```bash
python test_profile_accuracy.py
# 可选：--sample-size 10 指定样本数（默认 10）
```

**结果位置**  
`test_results/profile_accuracy_report.json`；若已运行标准 A，会生成/更新 `test_results/final_report.md` 供答辩展示。

## 三、环境与依赖

- **AI 服务**：需已启动（默认 `http://127.0.0.1:5002/api/v1`）
- **MySQL**：需可连接，且存在 `user_profiles`、`profile_skills`、`profile_certificates` 等表及测试数据
- **Python**：需安装 `mysql-connector-python` 或 `pymysql` 之一

以上两条标准均通过脚本自动化执行，结果可复现，满足赛题“量化的可执行标准”要求。
